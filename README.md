# ShareIt — P2P-платформа для совместного использования вещей

Бэкенд-приложение на базе Spring Boot, представляющее собой двустороннюю P2P-платформу (Peer-to-Peer) для шеринга и аренды предметов.

## 🚀 Ключевые технические и архитектурные фичи

*   **Двухуровневая архитектура (Gateway + Server):** Разделение на модули `gateway` (валидация, маршрутизация) и `server` (бизнес-логика и работа с БД).
*   **Жесткая валидация пересечения интервалов:** Алгоритм бронирования, исключающий наложение дат аренды и повторные бронирования.
*   **Пагинация** Постраничная выдача данных для оптимизации загрузки списков и снижения нагрузки на БД.
*   **Надежность и 90% покрытие тестами:** Модульные и интеграционные тесты с использованием Mockito и WebMvcTest.

## 🛠️ Технологический стек
*   **Язык и фреймворки:** Java 21, Spring Boot 3.x, Spring Data JPA, Hibernate.
*   **Базы данных:** PostgreSQL, H2 Database (для тестов).
*   **Тестирование и инструменты:** JUnit 5, Mockito, Docker, Maven, Lombok.

## 💻 Локальный запуск (Docker)
```bash
git clone git@github.com:krvdenis/java-shareit.git
cd java-shareit
docker compose up --build
```
После успешного старта сервис будет доступен по адресу: `http://localhost:8080`

## 📊 Выводы по результатам проекта

* **Минимизирована нагрузка на слой хранения данных:** Внедрение сквозной пагинации на уровне репозиториев и контроллеров жестко ограничило объемы разовых выборок из БД, снизив трафик между бэкендом и СУБД и оптимизировав потребление RAM.
* **Достигнут высокий уровень надежности системы:** Развитая тестовая модель позволила довести суммарное покрытие бизнес-логики до 90%. Это гарантирует стабильность работы критически важных алгоритмов (валидация интервалов дат) и исключает появление регрессионных ошибок.
* **Реализован надежный сетевой периметр (API Gateway):** Двухуровневая архитектура позволила перенести всю первичную валидацию DTO на входной шлюз, полностью разгрузив ядро приложения от обработки некорректных запросов.
